# Workflows — Central de Manutenção

Esta pasta contém os dois workflows do sistema de automação de solicitações de manutenção, desenvolvidos no n8n.

- **D9 — Abertura de Solicitações:** validação, classificação de prioridade, prevenção de duplicidades e registro dos chamados.
- **D10 — Acompanhamento de Solicitações:** sincronização de status entre Trello e Google Sheets e notificações automáticas.

Os arquivos são versões de demonstração e exigem configuração das integrações antes da execução.
